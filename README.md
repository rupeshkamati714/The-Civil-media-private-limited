# The Civil Media Private Limited — Version 2

## Included
- Public responsive news portal
- Supplied company logo
- Breaking-news ticker
- Search
- News categories
- Admin login and dashboard
- Add/Edit/Publish/Draft/Archive news
- Article counts and recent articles
- Basic company settings
- Nepali/English switch button placeholder
- Browser localStorage demo CMS

## Production
The included CMS is browser-local and is intended as a working prototype. For a real newsroom, connect the forms to a backend such as Node.js/Express + PostgreSQL/MySQL or Firebase/Supabase, add secure authentication, image storage, SEO, sitemap, analytics, and deployment.
